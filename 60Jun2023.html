Exchange Partner Portal Migrated to New Developer Distribution Portal

As of June 23rd, 2023, the Exchange Partner Portal has been migrated to the new Developer Distribution portal. In the new portal, you can review plugin acquisition reports, make changes to your listings without submitting a patch, and retract, recall, mark as pending and modify listings without contacting the review team. Read more about these updates in our previous blog post.

If you're having trouble logging in to the new portal, please read our FAQ. For any bugs or concerns, please reach out to the review team. Check out the new portal today!

InDesign v18.4 includes a breaking change for UXP Scripts
InDesign v18.4 has many enhancements for UXP Scripts, but, unfortunately also includes a breaking change. If you have written UXP scripts for InDesign in the past, the InDesign APIs that were available in the global scope now need to be included using require(). Please update and test your scripts.
